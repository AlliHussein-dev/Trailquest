# 🌍 TrailQuest

**Discover places. Plan adventures. Explore the world.**

TrailQuest is a modern travel discovery platform designed to help travelers explore destinations, discover interesting attractions, access real-world travel information, and organize their trips in one place.

## ✨ Features

- **Overview Dashboard** – Explore travel inspiration and trending destinations.
- **Discover Destinations** – Search and explore destinations around the world.
- **Destination Details** – View destination information, attractions, activities, and images.
- **Favorites** – Save interesting destinations for later.
- **My Trips** – Organize and manage travel plans.
- **Weather** – Check weather conditions for destinations.
- **Flights** – Access external flight-search platforms to explore available flights.

## 🛠️ Tech Stack

- React 19
- JavaScript (JSX)
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide React
- React Router

## 🎯 Vision

TrailQuest aims to make travel discovery and trip organization easier by bringing destination exploration, useful travel information, and travel planning together in one platform.
